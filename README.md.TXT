PROJECT TITLE:
LoopPractice – Java Loop Exercises

PURPOSE OF PROJECT:
This project was created to practice different types of loops in Java as part of the Foundations of Programming Technologies course.

The project includes four activities:
1. Countdown – Uses a while loop to print numbers from 5 to 1.
2. Multiplication Table – Uses a for loop to print the multiplication table of a given number from 1 to 10.
3. Playlist – Uses an enhanced for loop and ArrayList to display song names.
4. Christmas Tree – Uses nested for loops to print a Christmas tree pattern based on the given height.

VERSION or DATE:
9 November 2026

HOW TO START THIS PROJECT:
1. Open BlueJ.
2. Open the LoopPractice project.
3. Compile the LoopPractice class.
4. Right-click the class and create a LoopPractice object.
5. Right-click the object and select a method to run.

USER INSTRUCTIONS:
Run the following methods in BlueJ:

1. countdown()
   Prints a countdown from 5 to 1, followed by "Go!".

2. multiplicationTable(int number)
   Enter a number, such as 4, to display its multiplication table from 1 to 10.

3. printPlaylist()
   Displays four songs using an enhanced for loop and prints the total number of tracks.

4. printChristmasTree(int height)
   Enter a height, such as 4 or 6, to display a Christmas tree pattern in the terminal.

All results are displayed in the BlueJ Terminal.
